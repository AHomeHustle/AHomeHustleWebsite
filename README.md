# AHomeHustle Website

Welcome to the AHomeHustle website repository. This project contains the source code for the AHomeHustle website.

## Project Structure

```
AHomeHustleWebsite/
│
├── index.html           # Main HTML file
├── css/
│   ├── reset.css        # CSS reset/normalize
│   ├── variables.css    # CSS custom properties
│   └── styles.css       # Main styles
├── js/
│   └── main.js          # Main JavaScript file
├── images/
│   ├── hero.jpg         # Hero image
│   ├── logo.svg         # Logo
│   └── icons/           # Icon assets
├── assets/
│   └── fonts/           # Custom fonts
└── README.md            # This file
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start developing!

## Features

- Responsive design
- CSS custom properties for theming
- Clean and organized file structure
